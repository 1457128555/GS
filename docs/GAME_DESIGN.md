## 角色系统

### 角色构成

采用 LPC (Liberated Pixel Cup) 风格的分层精灵表系统：

```
角色 = 身体(body) + 头部(head) + 上衣(jacket) + 裤子(pants) + 鞋子(shoe) + 武器(sword)
```

### 装备等级

每个装备部位有 5 个等级：

| 部位 | Level 1 | Level 2 | Level 3 | Level 4 | Level 5 |
|------|---------|---------|---------|---------|---------|
| 头部 | 基础头盔 | 铁头盔 | 钢盔 | 精英头盔 | 传说头盔 |
| 上衣 | 布衣 | 皮甲 | 铁甲 | 钢甲 | 神圣铠甲 |
| 裤子 | 布裤 | 皮裤 | 铁裤 | 钢裤 | 神圣护腿 |
| 鞋子 | 布鞋 | 皮靴 | 铁靴 | 钢靴 | 神圣战靴 |
| 武器 | 木剑 | 铁剑 | 钢剑 | 精英剑 | 传说之剑 |

### 角色动作

| 动作 | 枚举值 | 帧数 | 是否循环 | 说明 |
|------|--------|------|----------|------|
| 待机 | `IDLE` | 1 | 否 | 静止状态 |
| 行走 | `WALK` | 9 | 是 | 移动中 |
| 斩击 | `SLASH` | 6 | 否 | 正面攻击 |
| 背斩 | `BACK_SLASH` | 6 | 否 | 背后攻击 |

### 角色方向

| 方向 | 枚举值 | 数值 |
|------|--------|------|
| 上 | `UP` | 0 |
| 左 | `LEFT` | 1 |
| 下 | `DOWN` | 2 |
| 右 | `RIGHT` | 3 |

## 游戏流程

### 玩家加入流程

```
观众发送弹幕 "加入"
    │
    ▼
系统检查是否已有角色
    │
    ├── 有 → 提示已存在
    │
    └── 无 → 创建新角色
            │
            ├── 分配随机位置
            ├── 初始装备（全部 Level 1）
            └── 加入游戏场景
```

### 角色升级流程

```
观众送礼物
    │
    ▼
系统识别礼物类型
    │
    ├── 小礼物 → 增加属性
    │
    └── 大礼物 → 升级装备
                    │
                    ├── 检查当前等级
                    ├── 升级对应部位
                    └── 更新角色外观
```

## 注意事项

### 抖音平台限制

- 内嵌页面需遵守抖音开放平台规范
- 注意审核敏感词过滤
- 礼物效果不能过于"氪金"导向

### 性能考虑

- 控制同屏角色数量（建议 < 50）
- 控制粒子特效复杂度
- 优化纹理图集打包

### 用户体验

- 新玩家引导
- 互动反馈要即时
- 避免长时间等待
